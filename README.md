# Local Circuits — design tokens

Public, token-only mirror of Local Circuits' design system, for importing into
[Open Design](https://github.com/nexu-io/open-design).

`globals.css` holds the canonical shadcn + Tailwind v4 token layer (brand palette,
typography, radius scale, light/dark) — identical to the app's `app/globals.css`,
which is already served publicly by the deployed site. **No application code here.**

Import in Open Design via: `https://github.com/tomkit/local-circuits-tokens`
